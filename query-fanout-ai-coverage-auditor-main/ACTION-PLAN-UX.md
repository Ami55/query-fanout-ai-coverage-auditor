# Action plan execution workflow

The Action Plan now turns audit findings into implementation tasks with:

- `Do now`, `Do next`, and `Monitor` queues
- clickable queue cards with a visible active-filter state and clear-filter control
- a plain-language three-step usage guide
- the problem and supporting evidence
- the exact page or content change required
- named owner, effort, impact, and status
- a five-point completion checklist
- post-publication verification at 14 and 28 days
- an explicit success metric

When the AI response omits an action plan, the app generates tasks from the current project’s coverage gaps and opportunities. Live actions never use showcase/demo data.

Priority labels such as `High priority` and `Medium priority` are normalised into the correct execution queue.
